# Contributing to ComposeCharts

First off, thank you for considering contributing to ComposeCharts! It's people like you that make ComposeCharts such a great tool.

## How Can I Contribute?

### Reporting Bugs
*   Check the [Issues](https://github.com/yourusername/ComposeCharts/issues) to see if the bug has already been reported.
*   If you can't find an open issue addressing the problem, [open a new one](https://github.com/yourusername/ComposeCharts/issues/new). Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements
*   Check the [Issues](https://github.com/yourusername/ComposeCharts/issues) to see if the enhancement has already been suggested.
*   If it hasn't, [open a new issue](https://github.com/yourusername/ComposeCharts/issues/new) and describe the feature you'd like to see.

### Pull Requests
*   Fill in the required template.
*   Do not include issue numbers in the PR title.
*   Follow the existing code style.
*   Include screenshots or GIFs if you are changing the UI.

## Development Setup

1.  Clone the repository: `git clone https://github.com/yourusername/ComposeCharts.git`
2.  Open the project in Android Studio.
3.  Run the `composeApp` module on an emulator or physical device.
